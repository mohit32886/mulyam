1. Platform Overview

Mulyam Jewels is a full-featured e-commerce platform for jewelry with dual applications: a customer-facing storefront and an admin portal. Uses Supabase for database, Cloudinary for images, and WhatsApp for checkout.

2. Detailed Architecture

Dual Build System

Mulyam uses separate Vite configurations for storefront and admin, allowing independent builds and deployments.
ConfigEntryOutputPort
vite.config.storefront.jsindex.htmldist/storefront5173
vite.config.admin.jsadmin.htmldist/admin5174

NPM Scripts

ScriptDescription
npm run devStart storefront dev server (5173)
npm run dev:adminStart admin dev server (5174)
npm run buildBuild storefront + generate sitemap
npm run build:adminBuild admin portal
npm run build:allBuild both applications

State Management

CartContext (Storefront)

src/context/CartContext.jsx

State: items, isOpen, appliedCoupon, couponDiscount
Actions: addToCart, removeFromCart, applyCoupon, getWhatsAppOrderLink
Storage: localStorage (mulyam-cart, mulyam-coupon)

AdminAuthContext (Admin)

src/admin/context/AdminAuthContext.jsx

State: isAuthenticated, user
Actions: login, logout
Storage: localStorage

Cart Features

Persistence

Cart items stored in localStorage under 'mulyam-cart' key. Survives page refresh and browser close.

Coupon Support

Apply percentage, fixed amount, or free shipping coupons. Validates against Supabase.

Free Shipping

Automatic free shipping on orders over Rs 1,499. Progress indicator shows remaining amount.

Computed Totals

Real-time calculation of subtotal, discount, and final total with item count.
